> - **COEP `credentialless` (updated 2026-06-04, FE↔BE wiring):** the Vite dev server uses `Cross-Origin-Embedder-Policy: credentialless` (not `require-corp`). `require-corp` kept `crossOriginIsolated` for the WASM decoders but **blocked cross-origin subresources without a CORP header** — specifically the scan images served from MinIO/S3 (and DICOM from the Orthanc/WADO proxy), which fail with `ERR_BLOCKED_BY_RESPONSE...COEP`. `credentialless` still yields `crossOriginIsolated === true` (SharedArrayBuffer/Cornerstone keep working) while letting those cross-origin GETs load. Same-origin `public/` workers + WASM are unaffected. Found and fixed during the end-to-end real-data smoke test (create patient → add study → upload X-ray to S3 → render in workspace).
